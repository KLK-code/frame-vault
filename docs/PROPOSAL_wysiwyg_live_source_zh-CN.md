# 提案：所见即所得编辑器 —— 光标所在块显示源码（Live Source）

> **状态：已废止（2026-09-23 当天废弃，代码已删除）。** 本方案（光标所在块整块翻成源码文本域）
> 当天实施并验收通过，但**同一天就被使用者否决**：反馈是"不想 markdown 文本里有这种特效、缩小我的选中范围"，
> 要的是 Typora / Obsidian 那种随心编辑的即时渲染。根因是引擎选型（ProseMirror 的文档是节点树，
> 要做到"就地露源码"只能把整块序列化成文本再换成控件，于是必然有盒子、有层切换、选区被困），
> 不是实现质量 —— 详见 `docs/PROPOSAL_editor_codemirror6_zh-CN.md` §1 的三条路线对比。
> **本文只作历史存档，不要照它施工**；写作台现在的编辑器内核是 CodeMirror 6。

## 背景与动机

写作台的所见即所得（Milkdown/ProseMirror）把语法符号完全藏起来了：想改一个已有块的 Markdown 结构
（把 `##` 升成 `###`、修链接地址、调表格列），只能靠选中文本 + 工具栏/快捷键，功率用户没有"直接改源码"的顺手通道。
参照 Obsidian 的 Live Preview：**平时整篇渲染，光标所在的那一块临时显示 Markdown 源码，光标离开立即恢复渲染**。

注：打字时 Milkdown 自带的 input rules 已能把 `# `、`- ` 顺手转成格式，所以痛点集中在**回头编辑已有内容**。

## 目标行为

1. 默认整篇所见即所得，与现状一致；
2. 光标（含点选、方向键移动）进入某个块 → 该块切换为源码态：显示并可直接编辑 Markdown 语法
   （`## 标题`、`- 列表`、`> 引用`、`**粗体**`、`[链接](url)`、表格管道符……）；
3. 光标离开该块 → 整块文本重新解析回节点树，恢复渲染态；
4. 源码态里粘贴/输入就是普通文本编辑（天然与现有 `handlePaste` 共存）；
5. 一次只有一个块处于源码态；空段落无语法可显示，保持普通文本行。

## 技术方案（推荐：块级文本化切换）

**模式先例**：`@milkdown/components` 的 code-block 组件就是这个模式 —— 光标进入代码块变编辑器、离开变渲染。
它用 CodeMirror 做源码编辑；我们**不做代码块**（代码块本来就常显源码），为标题/引用/列表/表格/段落做同款切换，
源码态用轻量文本编辑（textarea/contenteditable），不新增依赖。

**机制**：
- 用 `nodeViewCtx` 给目标块级节点注册自定义 NodeView，内部两个状态：渲染态（默认 DOM）与源码态（文本域）；
- 进入源码态：把当前节点用 `serializerCtx` 序列化成 Markdown 文本（单节点序列化：临时包一个 doc 再序列化），
  填入文本域，光标按字符偏移近似映射到源码位置；
- 离开源码态：文本用 `parserCtx`（现成，`handlePaste` 在用）解析回节点，`replaceWith` 换掉原块，
  光标反向近似映射回渲染态位置；解析异常则保留原节点不丢内容；
- 编辑期间不逐键回写 PM（避免受控回灌的老坑），**离开时一次性提交事务**，合并进撤销历史。

**分期**：
- **P1（块级）**：heading / blockquote / list-item / table —— 块级语法显示，价值最大、风险最低；
- **P2（段落 + 行内）**：段落整块文本化，行内记号（`**`、`` ` ``、链接）随整块文本化自然覆盖 —— 这是 Typora 的做法，
  避免 ProseMirror markView 逐 mark 切换的高风险实现。

## 硬约束（已有踩坑直接适用，AGENTS §9）

- **IME**：`compositionstart/end` 期间禁止视图切换；进出块时若组合进行中，推迟到组合结束；
- **撤销栈**：切换视图不得清撤销栈；文本态内的编辑并入 PM history；
- **受控回灌**：文本域不逐键 setState/replaceAll，只在进出块时同步一次；
- **粘贴**：`handlePaste` 的 Markdown 识别逻辑在渲染态照旧生效；源码态粘贴 = 纯文本插入；
- **性能**：只重建当前块，千行文档不允许整篇重解析；连续跨越多个块（按住方向键）时用防抖避免闪烁切换。

## 验收标准

- 光标进/出标题、列表项、引用、表格、段落，源码态与渲染态正确互切，语法字符只在源码态出现；
- 源码态把 `## ` 改成 `### `、改链接 URL，离开后结构正确变化；解析失败不丢原文；
- 中文输入法全程不断线；Ctrl+Z 行为符合直觉、不整段消失；
- 粘贴整篇 Markdown（现有能力）不回退；
- 千行文档滚动 + 光标移动无卡顿、无闪烁。

## 实施步骤（下一轮开工时）

1. 调研确认 NodeView 注册点与单节点序列化 API（`nodeViewCtx` + `serializerCtx`，均已在 @milkdown/core 暴露）；
2. P1 四类块 + 光标映射（初版允许近似映射）；
3. P2 段落文本化；

## 实施结果与偏差（2026-09-23 完工回填）

### 与提案不同的两处

1. **不用 NodeView，改用「节点装饰 + widget」**。提案写的是 `nodeViewCtx` 注册自定义 NodeView。
   动手时发现：标题 / 段落 / 引用 / 列表项 / 表格的排版规则（`li > p`、`.ProseMirror > *:first-child`、
   表格边框……）全挂在 ProseMirror **默认生成的 DOM** 上，NodeView 必须再包一层壳，层级一变换样式就整片歪，
   等于为了这个功能把所有排版规则重写一遍。改成两条装饰：`Decoration.node(...)` 给这一块挂
   `display:none`（**DOM 结构一个字不动**），`Decoration.widget(...)` 在它的位置插一个 `<textarea>`。
   隔离靠 widget 的 `stopEvent`（PM 无视文本域里的所有事件）与 `hasFocus()`（文本域持焦点时 PM 不抢 DOM 选区）。
   路数跟 `@milkdown/components` 的代码块组件一样，但不需要 CodeMirror。
2. **不做"反向光标映射"**。提案说离开时把光标近似映射回渲染态 —— 实际不需要：离开是用户自己点/按键造成的，
   ProseMirror 的选区本来就落在正确位置，再去动它反而容易打架。只有"进块"才做一次正向近似映射
   （把块内文本偏移映射到源码的字符位置）。

### 验收标准逐条结果（都在写作台真机操作过）

| 验收项 | 结果 |
|---|---|
| 光标进/出标题、列表项、引用、表格、段落互切，语法字符只在源码态出现 | ✅ 五类块逐个点过：编辑器里其余部分照常渲染，只有当前块换成文本域 |
| 源码态把 `## ` 改成 `### `、改链接 URL，离开后结构正确变化 | ✅ 把 `# ` 加成 `### `，离开后标题真的降了两级，存盘 JSON 里就是 `### 一级标题`；表格源码里改单元格后离开，表格内容跟着变 |
| 解析失败不丢原文 | ✅ 两道闸（`ReplaceStep.apply().failed` + 空结果兜底空段落）。解析不了时**原节点一个字不动**，源码态留在原地并显示提示，Esc 可放弃 |
| 中文输入法全程不断线 | ⚠️ **未能用自动化输入法实测**（见下） |
| Ctrl+Z 行为符合直觉、不整段消失 | ✅ 实测有效：源码态里那一次编辑是**一个**事务，Ctrl+Z 一步退回整块（不是逐字符倒）。**顺带修了一个既有缺陷**：`@milkdown/plugin-history` 在这个上下文里根本没生效，之前 Ctrl+Z 是静默无效的 |
| 粘贴整篇 Markdown（现有能力）不回退 | ✅ 粘一整篇含标题 / 行内记号 / 列表 / 引用 / 表格的 `.md`，一次成型 |
| 千行文档滚动 + 光标移动无卡顿、无闪烁 | ⚠️ **未做千行实测**（见下）；跨块连跳有 120ms 防抖，只让停下的那块翻面 |

### 无法验证的点（以及用户怎么自己确认）

- **中文输入法**：自动化通道只能发"整段文本"，没法真的走一遍拼音候选框。代码里按硬约束做了三件事：
  ①文本域自己的 `compositionstart/end` 期间不提交、不切块；②进块定时器触发时会再查一次
  `view.composing`；③PM 正在打字（`docChanged` 且没动光标）时一律不切。**确认方式**：在写作台里用拼音
  打一段中文，光标停在同一个块里打完，看候选框会不会被顶掉、字会不会重排。
- **千行文档性能**：没有现成的千行条目，没造。已知的代价只有两处：进块时序列化**这一个块**、
  敲字 250ms 后把整篇序列化一次做"投影"（给上层草稿用）。**确认方式**：造一篇长文，按住方向键从头走到尾。

## 风险

| 风险 | 应对 |
|---|---|
| 光标位置映射偏差（缩进/语法前缀宽度不同） | 初版接受近似映射；把映射函数收在单文件便于迭代 |
| 切换闪烁 / 抖动 | 只切当前块 + 跨块防抖；切换前后块高度尽量一致（源码态用同字号排版） |
| IME 与切换竞态 | 组合期间冻结切换（硬约束） |
| 解析回写失败丢内容 | 失败保留原节点 + 可见提示；源码文本先留底再替换 |
| 依赖蔓延 | 明确不引 CodeMirror / 不做整篇源码模式（整篇编辑已有 MarkdownField 承担） |
